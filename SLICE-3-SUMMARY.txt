  • Drag-to-pan with visual cursor feedback

  • Real-time zoom level indicator

State Management
  • Zustand: ephemeral UI (zoom, pan, selection, tool)

  • Debounced persistence (500ms)

Security

  • DB-level ownership validation
  • Input validation with Zod schemas
  • RFC 7807 error format

Performance
  • Lazy-loaded Konva libraries
  • Code splitting with Suspense
  • Debounced API calls
  • Optimized DB queries with indexes

📊 API ENDPOINTS

GET    /api/v1/canvases          → List user's canvases
GET    /api/v1/canvases/:id      → Get canvas by ID
PATCH  /api/v1/canvases/:id      → Update canvas (zoom/pan)

All endpoints:
  • Require authentication
  • Enforce ownership checks
  • Return RFC 7807 errors
  • Validate input with Zod

🚀 QUICK START

Setup:
  pnpm install
  cp .env.example .env
  # Edit .env with DATABASE_URL
  pnpm db:push

Development:
  pnpm dev              # Start dev server (localhost:3000)
  pnpm test             # Run unit tests
  pnpm test:e2e         # Run E2E tests
  pnpm type-check       # Type checking
  pnpm lint             # Linting

Usage:
  1. Navigate to http://localhost:3000
  2. Sign in (placeholder)
  3. Go to /canvas/[canvas-id]
  4. Mouse wheel to zoom
  5. Drag to pan
