# IMP-041 - Move authentication to Better Auth

<objective>
Better Auth replaces next-auth 5 beta with no forced logout surprises, no weaker
policy, and the handbook auth policy in place.
</objective>

<context>
Handbook auth policy: Argon2id hashing, verified email, passkeys,
authenticator-app two-factor, suitable OAuth providers, server-side sessions in
secure cookies, rate limits and lockout, account export and deletion. Memoria
already has Argon2, verification, reset tokens, lockout, exports and deletion.
The public address must equal the auth base URL exactly. The WebSocket upgrade
reads Auth.js cookie names (`src/lib/collaboration/websocket-server.ts`), and
the MCP OAuth server is separate and stays.
</context>

<files>
`src/lib/auth*`, `src/proxy.ts`, `src/app/api/auth/`, `prisma/schema.prisma`,
`src/lib/collaboration/websocket-server.ts`, `src/features/auth/`, `tests/`.
</files>

<steps>
1. Map current users, accounts, sessions, and tokens onto Better Auth tables in
   a Prisma migration; keep existing Argon2 hashes valid.
2. Swap session reading in the proxy, route handlers, server components, and
   the WebSocket upgrade behind one helper.
3. Port credentials sign-in, verification, reset, lockout, and session
   revocation; add passkeys and TOTP two-factor.
4. Remove `next-auth` and `@auth/prisma-adapter`.
</steps>

<acceptance>
- Existing accounts sign in after migration without a password reset.
- All auth E2E journeys and authorization tests pass unchanged in intent.
- Passkey and TOTP enrolment and sign-in are covered by tests.
</acceptance>

<verification>
`pnpm test -- --run`; real-PostgreSQL integration suite; `pnpm test:e2e`;
`pnpm type-check`; `pnpm lint`; `pnpm build`; `pnpm smoke`.
</verification>
