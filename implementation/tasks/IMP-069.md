# IMP-069 - Turn a pile into a checklist, table or summary

<objective>
On any pile (frame), one menu turns its items into a new note: a summary, a checklist, or a comparison table.
</objective>

<files>
`src/app/api/v1/ai/summarize/route.ts`, `src/lib/ai/service.ts`, frame menu under `src/features/canvas/components/`
</files>

<acceptance>
- The result is a new note placed next to the pile; the original items are untouched.
- Item content is capped by `AI_SUMMARY_ITEM_LIMIT` and `AI_SUMMARY_CONTENT_BYTES`; budget limits apply.
- The menu is hidden when AI is not configured.
</acceptance>

<verification>
`pnpm test -- --run` with a mocked provider for each output type; `pnpm lint`; `pnpm type-check`.
</verification>
