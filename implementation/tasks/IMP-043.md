# IMP-043 - Harden external fetches, uploads, and dependencies

<objective>
Server-side network requests are pinned to validated destinations, durable
request/content bytes and decoded images are bounded, and the production
dependency gate is green or has explicit expiring exceptions.
</objective>

<files>
`src/lib/utils/ssrf-protection.ts`, `src/lib/agents/webhooks.ts`,
`src/app/api/v1/unfurl/route.ts`, bookmark refresh jobs,
`src/app/api/v1/upload/route.ts`, canvas-item validation, CSP/CORS middleware,
`package.json`, `pnpm-lock.yaml`, security tests.
</files>

<context>
Combines Codex SEC-02 through SEC-05 and LOG-05 with the valid core of Opus
SEC-04, SEC-05, SEC-11, and SEC-12. Opus notices multipart buffering but misses
unbounded JSON/item structures and DNS time-of-check/time-of-use. Its SEC-13
claim is rejected: self-hosted Vercel Analytics requests the current-origin
`/_vercel/insights` route rather than beaconing directly to Vercel.
</context>

<steps>
1. Resolve once and pin each outbound connection to a vetted address while
   preserving Host/SNI; revalidate every redirect and reject mixed or changed
   private/reserved answers for unfurls and webhooks.
2. Enforce `FEATURE_BOOKMARK_UNFURLING` consistently in UI, API, and scheduler,
   failing closed when disabled.
3. Add serialized-byte and structural caps to every item content type, reject
   implausible content lengths early, and use the supported ingress/body limit
   from IMP-042 for chunked JSON/multipart enforcement.
4. Stream/bound multipart handling; cap image dimensions, decoded pixels,
   frames, and metadata, then normalize/re-encode or require an explicitly
   documented scanner policy for public/untrusted deployments.
5. Add correct `Vary: Origin` handling for reflected CORS responses and narrow
   CSP connection/image sources to documented consumers without breaking the
   selected deployment.
6. Upgrade or formally triage every production advisory. The 2026-08-10 rerun
   reports 5 High and 5 Moderate vulnerabilities.
</steps>

<acceptance>
- DNS rebinding, redirect changes, reserved addresses, oversized bodies/item
  structures, and decompression-bomb metadata fail within bounded resources.
- Feature-off prevents all bookmark network access.
- CORS/CSP behavior is cache-correct and tested in production shape.
- `pnpm audit --prod --audit-level=high` passes or each remaining advisory has
  proven non-reachability, owner, and expiry.
</acceptance>

<verification>
Hostile DNS/redirect/upload/body tests; production proxy tests; CSP report/browser
test; `pnpm audit --prod --audit-level=high`; `pnpm type-check`; `pnpm lint`.
</verification>
