# IMP-061 - Phone: "Share → Memoria" from any app

<objective>
On Android (installed PWA) a shared link or text lands in the Inbox; on iPhone, an Apple Shortcut does the same, because iOS PWAs cannot be share targets.
</objective>

<files>
`public/manifest.json`, new share-target page under `src/app/share-target/`, `src/proxy.ts`, `docs/` (Shortcut setup)
</files>

<acceptance>
- The manifest declares a `share_target` (title, text and url) pointing at an authenticated page that saves the link to the Inbox and shows a "Saved" screen with an optional "How should this be sorted?" note.
- An unauthenticated share goes through sign-in and then completes without losing the shared link.
- The save uses the same server path and validation as IMP-060.
- The docs include an iOS Shortcut that posts the shared URL to the clip endpoint with an API key.
</acceptance>

<verification>
`pnpm test -- --run` for the share-target handler; `pnpm gate e2e` for share-then-sign-in (needs DEC-002 machine).
</verification>
