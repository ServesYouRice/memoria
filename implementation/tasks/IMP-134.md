# IMP-134 - One search, and Ctrl K always opens it

<objective>
There is one place to search all canvases (the Search page) and Ctrl K
(Cmd K on a Mac) opens it from every signed-in page. The dashboard's
separate command list and second search pop-up are gone.
</objective>

<context>
Found in the UI audit of 2026-11-14. Today there are five ways to find
things:
1. the top-bar field "Search… Ctrl K" -> opens the `/search` page;
2. Ctrl K on the dashboard -> opens a different thing, the
   `CommandPalette` (4 commands: go to dashboard, create new canvas,
   search across canvases, switch theme);
3. that palette's "Search Across Canvases" -> opens a third thing, the
   `GlobalSearchDialog` pop-up;
4. the sparkle button "Ask" (`AskLauncher`, Ctrl J) -> AI questions;
5. "Search canvas" inside a canvas -> finds text on that canvas.
So the label "Ctrl K" on the search field is wrong on the dashboard.
Rule used (WCAG 3.2.4): one job, one name, one place.
After this card three clear tools remain: Search (all canvases), Ask
(AI), and "Search canvas" (this canvas only).
</context>
