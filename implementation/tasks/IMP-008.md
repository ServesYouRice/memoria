# IMP-008 — One geometry and capability contract

<objective>
Every item type persists move/resize through one path and every role sees only
the interactions it may perform.
</objective>

<files>
Canvas board/layer, every item component, interaction hook, comments/tools,
parameterized component/integration tests.
</files>

<steps>
1. Define required item-adapter props for capabilities and geometry commit.
2. Route drag/resize through one parent-owned serialized mutation path. Remove
   bookmark/image local duplicate writes.
3. Apply EDIT, COMMENT, VIEW, OWNER capabilities to stage tools, items, polls,
   comments, dialogs, and context menus before interaction.
4. Keep server authorization unchanged as the final boundary.
5. Parameterize tests over every item type, role, move, resize, success, failure,
   and version conflict.
</steps>

<acceptance>
- One gesture causes one durable geometry write.
- Unsupported roles cannot create local optimistic mutations.
- All supported item types persist or are explicitly non-movable.
</acceptance>

<verification>
Targeted canvas tests; `pnpm type-check`; `pnpm lint`.
</verification>
