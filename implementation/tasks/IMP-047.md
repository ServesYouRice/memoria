# IMP-047 - Real client identity behind the gateway

<objective>
Rate limits, account lockout and connection caps key on the real client, not the gateway's address, in the bundled stack and on k3s.
</objective>

<files>
`docker-compose.yml`, `scripts/setup.mjs`, `tests/unit/selfhost-config.test.ts`, `src/lib/network/client-ip.ts`, `Caddyfile`
</files>

<acceptance>
- Setup writes a `TRUSTED_PROXY_CIDRS` that covers the gateway network; the app, sync and worker services receive it.
- `pnpm doctor` warns when the app sits behind a proxy with an empty value.
- The infra repo note says which CIDR the k3s ingress needs.
</acceptance>

<verification>
`pnpm test -- --run`; `pnpm smoke` against the compose stack.
</verification>
