# IMP-107 - Standing notes for AI agents, per workspace

<objective>
The owner can leave standing notes for AI agents in each workspace ("how
we work here"), and connected agents receive them.
</objective>

<context>
Approved by the owner on 2026-11-11; a leading rival ships the same idea.
Agents connect through the MCP server and get one fixed set of
instructions (`MCP_SERVER_INSTRUCTIONS` in `src/lib/agents/mcp-schema.ts`,
`src/lib/agents/mcp.ts`). A `Workspace` has only a name.
</context>

<files>
`prisma/schema.prisma`, `src/lib/agents/mcp-schema.ts`,
`src/lib/agents/mcp.ts`, `src/app/api/v1/workspaces/`,
`src/app/workspaces/WorkspacesPageClient.tsx`,
`docs/agents/connect-ai-apps.md`, `tests/api/`.
</files>

<executor_constraints>
Schema change with a Prisma migration. Only the workspace owner can edit
the notes; they are length-limited and validated. Agents receive them
labelled as the owner's guidance, kept apart from item text, which stays
marked as data. The notes never loosen what an agent is allowed to do:
approvals and permissions are unchanged.
</executor_constraints>

<acceptance>
- Each workspace has a "Notes for AI agents" box with an example.
- An agent working in that workspace receives the notes; an agent without
  access to the workspace does not.
- Changes to the notes are recorded in the agent activity record.
- The guide for connecting AI apps explains the notes.
</acceptance>

<verification>
`pnpm test:file` for the MCP and workspace tests touched;
`pnpm gate fast`; `pnpm gate integration` on the dev machine.
</verification>
