# IMP-088 - One name for the same thing

<objective>
The app uses one word for a user's space. Today it says "canvas" in most
places and "board" in others, which reads like two different things.
</objective>

<context>
From the 2026-11-11 UI review. "My canvases" and "New canvas" on the
dashboard; "Ask your boards..." in
`src/features/command-palette/AskPalette.tsx` and about ten other on-screen
strings say "board". The owner picks the word in DEC-016.
</context>

<files>
`src/features/command-palette/AskPalette.tsx`, on-screen strings under
`src/app/`, `src/features/` and `src/components/`, email and notification
text, `tests/unit/`.
</files>

<executor_constraints>
Wording only. Do not rename routes, API fields, MCP tool names, database
names, file names or code identifiers.
</executor_constraints>

<acceptance>
- Every on-screen, email and notification string uses the chosen word.
- A unit test scans on-screen strings and fails if the other word returns
  (with an allowlist for code identifiers).
</acceptance>

<verification>
`pnpm test:file <new wording test>`; `pnpm gate fast`.
</verification>
