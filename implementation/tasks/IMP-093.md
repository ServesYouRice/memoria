# IMP-093 - Browser button saves the page you are on

<objective>
One click in the browser saves the current page, or the text you selected,
to the Inbox or a canvas you choose, without opening Memoria.
</objective>

<context>
Approved by the owner on 2026-11-11: a save button is the best-liked
feature of rival tools. Memoria already has "Memoria Tab Saver"
(`integrations/browser-extension/`, Manifest V3, Chrome, Edge and Firefox
128+), which saves every open tab to the Inbox and is installed by hand as
an unpacked extension. The single-page endpoint already exists:
`POST /api/v1/extensions/clip` accepts `url`, `title`, `selection`,
`canvasId` and `allowDuplicate` with an API key. No route lets an API key
list the person's canvases yet.
</context>

<files>
`integrations/browser-extension/`,
`src/app/api/v1/extensions/clip/route.ts`,
`src/lib/validation/extension.ts`, `src/lib/api/api-key-auth.ts`,

`tests/unit/browser-extension-popup.test.ts`,
`tests/api/extension-clip.test.ts`.
</files>

<executor_constraints>
- Ask the browser for the smallest permissions that work; no page content
  is read unless the person clicks save.
- Any new route for listing canvases is authenticated by API key,
  rate-limited, validated, and returns names and ids only.
- Publishing in the browser stores needs the owner's accounts and is not
  part of this card.
</executor_constraints>

<acceptance>
- The popup opens on "Save this page" and keeps "Save all tabs" as a
  second choice. Selected text is saved with the link.
- The person can pick a canvas; the last choice is remembered and the
  Inbox is the default.
- Right-clicking a page, a link or a selection offers "Save to Memoria",
  and a keyboard shortcut saves the page.
- A link that is already saved is reported with a way to open it, as the
  tab saver does today.
- One command builds store-ready packages for Chrome/Edge and Firefox, and
  the README explains installing and publishing.
</acceptance>
