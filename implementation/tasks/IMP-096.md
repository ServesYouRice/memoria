# IMP-096 - Open canvas files in and out

<objective>
People can move a canvas into and out of Memoria using open file formats,
so their work is never locked in.
</objective>

<context>
Approved by the owner on 2026-11-11. The export dialog offers PNG, PDF,
Markdown and Memoria's own JSON (`ExportDialog.tsx`,
`src/lib/export/export-utils.ts`), and nothing can be imported. Two free
formats matter: JSON Canvas 1.0 (`.canvas`, used by Obsidian: text, link,
file and group nodes joined by edges) and Excalidraw's `.excalidraw`
drawings.
</context>

<files>
`src/features/canvas/components/ExportDialog.tsx`,
`src/lib/export/export-utils.ts`, `src/lib/validation/canvas-item.ts`,
`src/app/api/v1/canvases/`, `src/lib/policy/capacity.ts`, `tests/unit/`,
`tests/api/`.
</files>

<executor_constraints>
- An imported file is untrusted: size limit, Zod validation, plain text
  only, links limited to `http` and `https`, and no file paths followed.
- Import goes through the validated HTTP routes in one transaction and
  respects the canvas and item limits.
- Read each format's current published description before mapping it.
</executor_constraints>

<acceptance>
- Export offers `.canvas`: notes and text become text nodes, bookmarks
  become link nodes, frames become groups, attached arrows become edges.
  What the format cannot hold (free drawings) is listed before the export.
- Importing a `.canvas` file creates a new canvas with the same layout.
- Importing a `.excalidraw` file creates a new canvas with its shapes,
  text, arrows and free drawings.
- After an import the person sees what was brought in and what was left
  out, with counts.
- A canvas exported as `.canvas` and imported again keeps its notes,
  links, groups and arrows.
</acceptance>

<verification>
`pnpm test:file` for the new converters and routes; `pnpm gate fast`;

</verification>
