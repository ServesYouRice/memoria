# IMP-001 — Reliable private image reads

<objective>
Image reads never consume the 10/hour upload-write bucket, stream without a
second full buffer, cache privately, and show a recoverable error in the canvas.
</objective>

<files>
`src/proxy.ts`, `src/middleware/rate-limit.ts`,
`src/app/api/v1/uploads/[assetId]/route.ts`, `ImageItem.tsx`, relevant tests.
</files>

<steps>
1. Apply the upload limiter only to `POST /api/v1/upload`. Give asset GETs an
   appropriate read policy; never match them by the singular prefix.
2. Stream the authorized S3 body. Remove redundant byte copying. Return a
   stable `ETag` and private cache headers; honor conditional GET when practical.
3. Track image load state. Render filename/icon plus Retry on failure.
4. Add a route matrix proving `/upload` and `/uploads/:id` use different
   buckets, route tests for streaming/cache headers, and an image error test.
</steps>

<acceptance>
- Eleven authorized image reads do not return upload-limit 429s.
- Asset authorization remains unchanged; private objects never become public.
- Failed images are visible and retryable.
</acceptance>

<verification>
`pnpm test -- --run`; `pnpm type-check`; `pnpm lint`.
</verification>
