# IMP-046 - Version history from snapshots

<objective>
Canvases take automatic snapshots while edited, thin them out over time, and offer a history panel to preview and restore versions.
</objective>

<files>
`prisma/schema.prisma` (`CanvasVersion`), `src/app/api/v1/canvases/[canvasId]/versions/`, `src/lib/outbox/`, `scripts/scheduler.mjs`
</files>

<acceptance>
- At most one automatic snapshot per interval, only after changes; jobs are safe to run twice.
- Retention thins automatic snapshots and never deletes manual versions.
- Viewers list and preview; only editors and owners restore (enforced over HTTP).
</acceptance>

<verification>
Route and unit tests; PostgreSQL integration tests for idempotency and retention; `pnpm build`.
</verification>
