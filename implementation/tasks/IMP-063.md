# IMP-063 - AI sorting that follows your instructions

<objective>
"Sort into piles" can use the configured AI to group items by meaning and to follow a written instruction (for example "by project; anything about travel together"), including the note saved with an IMP-061 or IMP-062 batch.
</objective>

<files>
`src/lib/agents/piles.ts`, `src/app/api/v1/canvases/[canvasId]/organize/route.ts`, `src/features/canvas/components/SortIntoPilesDialog.tsx`, `src/lib/ai/service.ts`
</files>

<acceptance>
- The Sort dialog has an optional instruction box, prefilled from the latest batch note when there is one.
- With AI configured (IMP-060), the AI returns piles that are checked against `pilesSchema` and limited to item ids that exist on the canvas; an invalid answer falls back to the current word-matching sort with a visible notice.
- Without AI, the current word-matching sort runs unchanged.
- The result is still a suggestion: nothing moves until the owner approves it, and it can be undone in one step.
- Item text sent to the AI respects the existing prompt-size and budget limits.
</acceptance>

<verification>
`pnpm test -- --run` with a mocked provider (valid, invalid and unknown-id answers, no-AI fallback); `pnpm lint`; `pnpm type-check`.
</verification>
