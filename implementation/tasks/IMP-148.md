# IMP-148 - Release command

<objective>
One command builds the image, tags it with the commit, pushes it, prints
the digest, and stops on a high Trivy or audit finding (handbook ME-01 and
`standards.md`).
</objective>

<context>
There is no release command today; infra pins images by digest.
</context>

<files>
`package.json`, a new `scripts/release.mjs`, `docs/operations/`.
</files>

<acceptance>
- Build, tag `<commit>`, push, print digest.
- Trivy (image) and `pnpm audit` run first; a high finding stops it.
- A dirty worktree stops it.
</acceptance>

<verification>
Dry run against a local registry; a planted high finding stops the run.
</verification>
