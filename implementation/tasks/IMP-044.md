# IMP-044 - Signed embeds with per-embed framing rules

<objective>
An owner can embed a canvas on chosen sites through a signed, revocable embed
token, while all other framing stays blocked.
</objective>

<context>
Today every response sends `X-Frame-Options: DENY`
(`src/lib/security/headers.ts`). Embeds need a read-only route whose CSP
`frame-ancestors` comes from the embed's allow-list, and the global deny must
stay for every other route.
</context>

<files>
`src/lib/security/headers.ts`, `src/proxy.ts`, `prisma/schema.prisma`,
`src/app/` (new embed route and owner settings), `tests/`.
</files>

<steps>
1. Add an embed model (canvas, allowed origins, expiry, revoked flag) and
   owner-only HTTP routes with Zod validation.
2. Serve a read-only embed page that verifies the signed token and sets
   `frame-ancestors` to the allowed origins only.
3. Add owner UI to create, list, and revoke embeds.
</steps>

<acceptance>
- An allowed origin can frame the embed; any other origin is refused.
- A revoked or expired token stops working at once.
- Non-embed routes still send `DENY`.
</acceptance>

<verification>
`pnpm test -- --run`; `pnpm test:e2e`; `pnpm type-check`; `pnpm lint`;
`pnpm build`.
</verification>
