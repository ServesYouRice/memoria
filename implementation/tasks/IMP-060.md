# IMP-060 - Browser extension: save all tabs to Memoria and close them

<objective>
On desktop Chrome, Edge and Firefox, one click saves every open tab as a link in Memoria's Inbox, optionally with a note on how to sort them, and then closes the tabs.
</objective>

<files>
New `integrations/browser-extension/` (Manifest V3, WebExtension API), `src/app/api/v1/extensions/clip/route.ts`, `src/lib/validation/extension.ts`, API key settings UI
</files>

<acceptance>
- The popup lists the tabs in the current window, preselects the normal web tabs (pinned and `chrome://` tabs are skipped by default), and has an optional "How should these be sorted?" text box.
- A new batch clip endpoint takes up to 100 links plus the note in one request and needs API-key auth, Zod validation and rate limits. It creates the items in one transaction on the Inbox canvas and returns their ids. Sending the same batch twice creates no duplicates (idempotency key).
- Tabs close only after the server confirms the save; on failure they stay open and the popup shows the error.
- A non-empty sorting note is stored with the batch so IMP-062 can use it.
- The extension stores the Memoria URL and API key in `storage.local`; setup is a paste-the-key screen.
</acceptance>

<verification>
`pnpm test -- --run` for the batch route (auth, validation, idempotency, capacity); `pnpm test:file` for the route; extension loads unpacked in Chromium via Playwright and saves the open tabs against the dev server.
</verification>
