# IMP-070 - Weekly recap and tidy-up of old links

<objective>
Once a week the user gets a short recap (what they saved, suggested piles, links untouched for a long time) with one-tap "archive these"; archived links keep their summary.
</objective>

<files>
`src/lib/outbox/`, `src/lib/email/templates.ts`, `src/lib/retention/`, `src/app/api/v1/notifications/`, Settings UI
</files>

<acceptance>
- A scheduled job writes one recap per user per week; running it twice in the same week sends one recap.
- The recap arrives as an in-app notification and, if the user opts in, an email; the default is in-app only.
- "Archive these" moves stale links to the trash-backed archive in one ChangeSet that can be undone; nothing is deleted automatically.
- "Stale" (default 6 weeks without opening) is a user setting.
</acceptance>

<verification>
`pnpm test -- --run` (once-per-week idempotency, opt-in email, undo); `pnpm gate integration` for the scheduled job.
</verification>
