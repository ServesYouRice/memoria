# IMP-036 - Gated features and rich-text UI

<objective>
The launch UI matches the selected template, undo/redo, poll, and rich-text
contracts instead of advertising disabled commands or editing a lossy format.
</objective>

<context>
DEC-003 through DEC-005 selected `hide`; DEC-006 selected
versioned Tiptap JSON. Their backend enforcement is archived with IMP-010
through IMP-013 under `../archive/2026-08-01/tasks/`.
</context>

<steps>
1. Remove template creation/use actions from launch navigation and dialogs while
   keeping stored template data untouched.
2. Remove undo/redo buttons and keyboard shortcuts that target unsupported
   command paths.
3. Remove poll creation/voting affordances and render preserved poll data only
   in the explicitly supported inert form.
4. Bind note creation/editing/rendering to the versioned safe Tiptap JSON
   contract, including visible normalization and the legacy-content bridge.
5. Add UI tests proving gated features are absent and supported formatting
   round-trips without silent loss.
</steps>

<acceptance>
- No launch UI or shortcut advertises a template, undo/redo, or poll mutation
  rejected by its API boundary.
- Existing gated data remains preserved and safely readable where supported.
- Supported formatted notes round-trip exactly through create and edit UI.
- Unsupported rich content is rejected or visibly normalized, never silently
  stripped.
</acceptance>

<verification>
Targeted feature/editor UI tests; `pnpm type-check`; `pnpm lint`.
</verification>
