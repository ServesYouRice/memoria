# IMP-152 - Direct browser uploads; password-reset mail through the outbox

<objective>
Browsers upload straight to object storage with short-lived signed URLs,
and password-reset mail is sent through the outbox (handbook ME-05).
</objective>

<context>
Uploads pass through the app today with a 5 MB cap. Reset mail is sent in
the request; a mail outage loses it.
</context>

<files>
Upload routes and client, `src/lib/storage`, the outbox worker, auth mail.
</files>

<acceptance>
- Signed upload URL with size and type limits; the server confirms the
  object before saving the item.
- Reset mail is enqueued and safe to send twice.
</acceptance>

<verification>
`pnpm gate integration`; `pnpm gate e2e` for upload and reset.
</verification>
