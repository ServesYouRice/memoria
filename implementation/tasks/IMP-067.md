# IMP-067 - Clear production dependency advisories

<objective>
`pnpm audit --prod --audit-level=high` passes, so the Production Dependency
Audit job and the jobs that wait on it (Build, Production E2E) run again.
</objective>

<context>
On 2026-10-24 the audit reported 8 advisories (2 critical, 3 high, 3
moderate), including unauthenticated remote code execution in `next` (patched
in >=16.3.3 / >=16.4.1), a `@sentry/nextjs` tunnel middleware bypass
(>=10.75.2), a `dompurify` sanitizer bypass (>=3.4.17), and ReDoS in
`@tiptap/core` (>=3.30.5). Dependabot PR #63 bumps the production group and
may cover part of this.
</context>

<files>
`package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml` (overrides).
</files>

<steps>
1. Upgrade the affected direct dependencies within their majors; use
   `pnpm.overrides` only for transitive packages with no direct upgrade.
2. Re-run the audit and the full verification set below.
</steps>

<acceptance>
- `pnpm audit --prod --audit-level=high` exits 0.
- No override pins a version below its advisory's patched range.
</acceptance>

<verification>
`pnpm audit --prod --audit-level=high`; `pnpm lint`; `pnpm type-check`;
`pnpm test -- --run`; `pnpm build`.
</verification>
