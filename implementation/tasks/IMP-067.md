# IMP-067 - Agents can write on cards and make boards

<objective>
Hermes, OpenClaw and other MCP agents can add a summary or note to an existing item and create a board, so they can read links overnight, run errands ("find 5 hotels, put them on my trip board") and keep their own notes on a board the user can see.
</objective>

<files>
`src/lib/agents/mcp.ts`, `src/lib/agents/mcp-schema.ts`, `src/lib/agents/policy.ts`, `integrations/skills/memoria/SKILL.md`
</files>

<acceptance>
- New MCP tools: `items_annotate` (append a summary or note to an item, never replace user text), `boards_create`, and `boards_list`; `inbox_save` accepts a target board.
- Each tool checks the agent's capability rung and canvas scope like the existing write tools; writes are recorded as agent actions and can be reverted.
- The skill gains short recipes for: overnight reading (summarize unread links with `items_annotate`), morning brief (search recent unread items, reply with three), errands (create or reuse a board, save results as a pile), reminders (use the agent's own scheduler, link back to the item), and agent memory (keep notes on a board named by the agent).
- Skill version bumps; tool names in the skill match the server.
</acceptance>

<verification>
`pnpm test -- --run` (tool schemas, scope and capability refusals, revert); `pnpm test:file` for the MCP route.
</verification>
