# IMP-075 - Buttons stay readable in every state

<objective>
Every button label can be read in every state. Today a greyed-out main
button shows faded dark text on the purple gradient, and the sign-up button
at the bottom of the home page shows purple text on purple.
</objective>

<context>
Found in the 2026-11-11 UI review on a local dev build. The theme's
contained-primary button variant in `src/lib/theme.ts` sets
`background: gradients.brand`. That `background` stays on `.Mui-disabled`
(whose text is `rgba(0,0,0,0.26)`) and beats a page-level `bgcolor`. Seen on
Settings ("Save profile", "Update password" while disabled) and on the
bottom call-to-action of `src/app/page.tsx` (`bgcolor: "#fff"`,
`color: "primary.main"`).
</context>

<files>
`src/lib/theme.ts`, `src/app/page.tsx`, `tests/unit/`.
</files>

<acceptance>
- A disabled main button has a flat muted background, no gradient, and a
  label with at least 3:1 contrast, in light and dark.
- The home page's bottom sign-up button label has at least 4.5:1 contrast
  against its own background, also on hover and focus.
- Enabled main buttons look the same as before.
- A unit test fails if the disabled style brings the gradient back.
</acceptance>

<verification>
`pnpm test:file <new test>`; `pnpm gate fast`; screenshots of Settings
(disabled save button) and the home page bottom section, light and dark.
</verification>
