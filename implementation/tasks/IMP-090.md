# IMP-090 - Real links and finger-sized buttons

<objective>
Canvas cards behave like normal links (open in a new tab, right-click,
screen readers), and small icon buttons are easy to hit with a finger.
</objective>

<context>
From the 2026-11-11 UI review. Dashboard cards navigate with
`router.push("/canvas/" + id)` on click (`DashboardContent.tsx`,
`CanvasCard.tsx` with `CardActionArea`), so Ctrl/Cmd-click and middle-click
do nothing. Top-bar icon buttons are 40x40px; the usual minimum for touch
is 44x44px.
</context>

<files>
`src/features/dashboard/components/CanvasCard.tsx`,
`src/features/dashboard/components/DashboardContent.tsx`,
`src/app/shared/` (`SharedCanvasesContent`),
`src/components/layout/AppShell.tsx`,
`src/features/canvas/components/MainToolbar.tsx`, `tests/unit/`.
</files>

<acceptance>
- Canvas cards on Dashboard and Shared are real links: Ctrl/Cmd-click and
  middle-click open a new tab and right-click shows the link menu. The
  checkbox and card menu still work without opening the canvas.
- Tab reaches each card once and Enter opens it.
- Icon buttons in the top bar, canvas toolbars and card menus have a hit
  area of at least 44x44px on touch screens.
- A unit test checks that a card renders a link with the right address; the
  dashboard selection tests pass.
</acceptance>
