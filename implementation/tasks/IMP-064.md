# IMP-064 - Saved links name, tag and explain themselves

<objective>
Every link saved to Memoria (clip, batch clip, share target, agent `inbox_save`) gets a clear title, a few tags and a two-line "what is this" summary without the user doing anything.
</objective>

<files>
`src/app/api/v1/unfurl/route.ts`, `src/lib/outbox/`, `src/lib/ai/service.ts`, `src/lib/ai/budget.ts`, `src/app/api/v1/extensions/clip/route.ts`, `src/lib/agents/mcp.ts`
</files>

<acceptance>
- Saving enqueues one outbox job per item; the job unfurls the page, then (with AI configured, IMP-060) writes title, tags and summary. Without AI, it keeps the unfurled title and description only.
- The job is safe to run twice: it never overwrites a title or tags the user edited, and it records which fields it filled.
- Users can turn it off in Settings; it respects the daily AI budget and skips quietly when the budget is spent.
- Page text sent to the AI is capped by `AI_MAX_PROMPT_BYTES`; fetches go through the existing SSRF-safe unfurl path.
</acceptance>

<verification>
`pnpm test -- --run` (job idempotency, user-edit protection, no-AI path, budget skip); `pnpm gate integration` for the outbox job.
</verification>
