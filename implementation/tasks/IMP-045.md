# IMP-045 - Offline canvas edits

<objective>
Editors keep editing an open canvas while offline; changes persist locally (per user and canvas), sync through the validated path on reconnect, and are discarded when refused or access is lost.
</objective>

<files>
`src/lib/collaboration/sync/client-session.ts`, `src/lib/hooks/use-canvas-document*`, `src/features/canvas/components/CanvasHeader.tsx`
</files>

<acceptance>
- Offline edits survive a reload and sync on reconnect.
- Refused or unauthorized local changes are discarded, never resurrected.
- The local cache is cleared on sign-out and never shared between users.
- The header shows offline / unsaved / synced.
</acceptance>

<verification>
Focused unit tests; `pnpm test -- --run`; an offline E2E spec through `pnpm gate e2e`.
</verification>
