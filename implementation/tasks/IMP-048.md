# IMP-048 - Rate-limit budgets per user and per route

<objective>
Ordinary use (image-heavy canvases, several tabs, notification polling) never hits 429, while abuse is still limited.
</objective>

<files>
`src/proxy.ts`, `src/middleware/rate-limit.ts`, `src/lib/constants.ts`, `src/app/api/v1/uploads/[assetId]/route.ts`
</files>

<acceptance>
- Authenticated requests are limited per user as well as per IP.
- Asset GETs and the unread-notification poll have their own budgets.
- A canvas with 150 images loads without a 429.
</acceptance>

<verification>
Route and middleware tests; `pnpm test -- --run`.
</verification>
