# IMP-021 — Proven backup and recovery

<objective>
Meet DEC-010 with verified database plus object-storage recovery and an
exercised incident path.
</objective>

<steps>
1. Upload a versioned authenticated manifest/checksum with each database backup.
   Verify before decompression and restore SQL with `ON_ERROR_STOP` into a clean
   target.
2. Back up/replicate object storage with inventory and consistency markers that
   align with database lifecycle state.
3. Pin/encrypt/retain artifacts according to the selected RPO/RTO. Monitor failed
   or stale backups.
4. Write one concise operator runbook for restore, integrity checks, app read/
   write smoke, rollback/forward-fix, secret rotation, and ownership.
5. Run a timestamped isolated drill; record duration, recovered counts, hashes,
   representative reads/writes, and deviations on the DONE row or external
   evidence link.
</steps>

<acceptance>
- Corrupt/partial backups fail closed.
- Restored canvases include their authorized uploaded assets.
- Measured RPO/RTO meet the selected target.
</acceptance>

<verification>
Backup/restore script tests plus one real drill in the named environment.
</verification>
