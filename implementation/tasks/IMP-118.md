# IMP-118 - AI sorting tests do not depend on a live Redis allowance

<objective>
`tests/unit/ai-sort-piles.test.ts` and
`tests/api/canvas-organize-route.test.ts` pass however many times they ran
today.
</objective>

<context>
Found on 2026-11-12: with `REDIS_URL` set in `.env`, these unit tests count
against the real daily AI allowance in the local Redis
(`memoria:ai:budget:<date>:u1`). After many runs in a day the allowance is
spent and 8 tests fail with "AI allowance reached". `resetAiBudgetForTests`
resets only the in-memory store.
</context>

<files>
`src/lib/ai/budget.ts`, `tests/unit/ai-sort-piles.test.ts`,
`tests/api/canvas-organize-route.test.ts`, `vitest.config.ts`.
</files>

<executor_constraints>
Unit tests must not read or write shared Redis state. Do not weaken the
budget checks themselves.
</executor_constraints>

<acceptance>
- The two test files pass when run 20 times in a row on a machine with the
  local Redis running.
</acceptance>

<verification>
`pnpm test:file tests/unit/ai-sort-piles.test.ts` repeated; `pnpm gate fast`.
</verification>
