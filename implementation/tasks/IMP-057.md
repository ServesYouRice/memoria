# IMP-057 - Image proxy so the CSP can drop `img-src https:`

<objective>
External images (bookmark previews and favicons, image items with remote
URLs, OAuth avatars) load through a same-origin proxy, so the CSP `img-src`
lists only Memoria's own and storage origins.
</objective>

<files>
`src/middleware/csp.ts`, the bookmark/unfurl code under `src/lib/`, image
item rendering in `src/features/canvas/`, embed pages under `src/app/embed/`.
</files>

<acceptance>
- `img-src` no longer contains `https:`; bookmarks, embeds and image items
  still show their images.
- The proxy reuses the SSRF protections of link unfurling, caps size and type,
  and caches.
</acceptance>

<verification>
CSP and proxy tests; `pnpm test -- --run`; `pnpm gate e2e`.
</verification>
