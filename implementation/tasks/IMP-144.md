# IMP-144 - Container image under 1 GB

<objective>
The production image no longer carries webpack's build cache and weighs
under 1 GB.
</objective>

<context>
The 2026-11-12 rehearsal run (handbook `board.md` RUN-ME-2,
`before-production.md` memoria step 2) measured the image at 1.97 GB, about
1 GB of it `.next/cache` copied by `COPY --from=build ... /app/.next`.
</context>

<files>
`Dockerfile`, `.dockerignore`.
</files>

<acceptance>
- `.next/cache` is not in the runtime stage.
- The image starts and `pnpm smoke` passes against it.
</acceptance>

<verification>
`pnpm gate container`; `docker image ls` shows the size.
</verification>
