# IMP-153 - A way to issue sign-up invites

<objective>
In production (`REGISTRATION_MODE=invite`) the owner can invite a second
person, who can then sign up.
</objective>

<context>
Handbook RUN-ME-1 / INF-32: nothing in Memoria creates a
`RegistrationInvite`, so only the owner could ever sign up
(`src/lib/auth/registration.ts`). DEC-024: keep invite-only; the owner
issues invites from a Settings page and a command.
</context>

<files>
`src/lib/auth/registration.ts`, an admin page or `scripts/` command, mail.
</files>

<acceptance>
- An invite is created for an email with an expiry; the token is stored
  hashed; the link is mailed or shown once.
- A second person signs up in production mode with it.
</acceptance>

<verification>
`pnpm gate integration`; `pnpm gate e2e` sign-up with invite.
</verification>
