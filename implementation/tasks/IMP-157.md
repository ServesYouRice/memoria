# IMP-157 - Passkeys stay off on the cluster

<objective>
`PASSKEYS_ENABLED` keeps its `true` default for self-hosters, `DEPLOYMENT.md`
says plainly that the cluster must set it to `false` until the final domain
(handbook OWN-07, CHK-ME-2), and a test proves that off means the passkey
endpoints refuse.
</objective>

<files>
`src/lib/env.ts`, `src/lib/auth/server.ts`, `DEPLOYMENT.md`, `tests/`.
</files>

<acceptance>
With `PASSKEYS_ENABLED=false` every passkey endpoint answers with a refusal.
</acceptance>
