# IMP-106 - Your own tagging rules

<objective>
A person can tell the AI in their own words how they like things tagged,
and new tags follow those rules.
</objective>

<context>
Approved by the owner on 2026-11-11; this is among the most requested
extras in a rival open-source link saver. Memoria's tags come from fixed
prompts (`src/lib/ai/enrich-link.ts`, `/api/v1/ai/tags`). The prompt
already marks page content as untrusted data.
</context>

<files>
`src/lib/ai/enrich-link.ts`, `src/app/api/v1/ai/tags/route.ts`,
`src/app/settings/`, `prisma/schema.prisma`, `tests/unit/`, `tests/api/`.
</files>

<executor_constraints>
The rules are the person's own text: stored per person with a Prisma
migration, length-limited, validated, and counted inside the existing
prompt size cap. Page content stays marked as data and can never change
the rules.
</executor_constraints>

<acceptance>
- Settings has a box "How should things be tagged?" with an example (for
  instance: "Use few tags. Prefer the tags I already have. Tag recipes
  with the main ingredient.").
- New automatic tags follow the rules; tags the person set by hand are
  never replaced.
- Emptying the box returns to the standard behaviour.
</acceptance>

<verification>
`pnpm test:file` for the tagging tests touched; `pnpm gate fast`;
`pnpm gate integration` on the dev machine.
</verification>
