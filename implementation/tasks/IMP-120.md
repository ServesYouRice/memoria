# IMP-120 - "Page not found" says so in plain words

<objective>
The not-found page says "Page not found" plainly, fits any wrong address
(not only canvases), and looks like the rest of the app.
</objective>

<context>
Found in the UI audit of 2026-11-14. `src/app/not-found.tsx` is shown for
every wrong address. Today it shows a giant "404", the heading "Page not
found", and the text "Oops! The canvas you're looking for seems to have
wandered off into the infinite void. Let's get you back on track." A person
who mistyped `/settings/xyz` is told a canvas is missing. The page also has
its own background wash and no Memoria logo.
Rule used (GOV.UK "page not found" pattern): say "Page not found", in plain
words, with no error-code number and no jokes.
</context>

<files>
`src/app/not-found.tsx`, `src/components/MemoriaLogo.tsx` (reuse, do not
edit), `tests/unit/not-found-client-boundary.test.ts`.
</files>

<executor_constraints>
- Keep the file a client component (`"use client"` stays on line 1).
- Keep the HTTP status 404. Do not add a redirect.
- Do not add new dependencies or new shared components.
</executor_constraints>

<steps>
1. Delete the element that renders the text `404`.
2. Make "Page not found" the page's only `h1` (`component="h1"`).
3. Replace the whole "Oops! ... back on track." paragraph with exactly:
   `The link may be old or mistyped.`
4. Buttons, in this order:
   - contained button, text `Go to my canvases`, `href="/dashboard"`;
   - outlined button, text `Search`, `href="/search"`.
   Remove the old "Go to dashboard" and "Go home" buttons.
5. Put `<MemoriaLogo size={32} />` followed by the word `Memoria` in the
   top-left corner as a link to `/` with `aria-label="Memoria home"`.
6. Remove the decorative overlay `Box` that uses `surfaces.hero` and any
   bordered or tinted box around the text, so the text sits directly on
   `background.default`. Remove imports that become unused.
7. Search `tests/` for `404`, `Oops` and `wandered`. Update any test that
   expects the old text to expect the new text.
8. Add `tests/unit/not-found-page.test.tsx` (copy the header of
   `tests/unit/canvas-item-list-row-buttons.test.tsx` for the happy-dom
   setup). It renders the default export and checks every acceptance line
   below that is about text or links.
</steps>

<acceptance>
- The rendered page contains none of: `404`, `Oops`, `void`, `canvas you`.
- There is exactly one `h1` and its text is `Page not found`.
- The text `The link may be old or mistyped.` is shown.
- A link `Go to my canvases` points to `/dashboard`; a link `Search` points
  to `/search`; a link named `Memoria home` points to `/`.
- At 390px wide nothing is cut off and the page does not scroll sideways.
</acceptance>
