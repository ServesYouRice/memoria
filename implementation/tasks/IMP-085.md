# IMP-085 - Canvas notes and background look finished

<objective>
The canvas looks like a pleasant pinboard, not a wireframe: notes look like
real sticky notes in a few colours, on a calm dotted background.
</objective>

<context>
From the 2026-11-11 UI review. `NoteItem.tsx` draws a flat `#FFFACD`
rectangle with a `#FFD700` border and Arial text; `GridOverlay.tsx` draws
grid lines in `#e0e0e0`. Note content is validated by `noteContentSchema` in
`src/lib/validation.ts` and today holds only `text`. Item writes go through
the validated HTTP routes and live edits through the sync server.
</context>

<files>
`src/features/canvas/components/NoteItem.tsx`,
`src/features/canvas/components/BookmarkItem.tsx`,
`src/features/canvas/components/GridOverlay.tsx`,
`src/features/canvas/components/ReadonlyCanvasItemLayer.tsx`,
`src/lib/validation.ts`, `tests/e2e/visual/canvas-visual.spec.ts`.
</files>

<executor_constraints>
- The note colour is an optional, validated field chosen from a fixed list;
  notes without it stay yellow. Check every reader and writer of note
  content (HTTP routes, sync server, import/export, MCP tools, AI features)
  so none rejects or drops the field. A Prisma migration is needed only if a
  database column or constraint changes.
- Dragging stays smooth with 200 notes on screen (cache or drop shadows
  while dragging).
</executor_constraints>

<acceptance>
- Notes have rounded corners, a soft shadow, the app's text font and
  comfortable padding; a selected note is outlined in the brand colour.
- A note can be set to one of about six colours; the choice is saved,
  survives a reload and reaches collaborators live.
- The background shows faint dots by default; the grid switch still works.
- The read-only view, card previews and PNG/PDF export show the same look,
  in light and dark.
</acceptance>

<verification>
`pnpm test:file` for the validation and note tests touched; `pnpm gate
fast`; `pnpm gate integration` if stored data or SQL changes; `pnpm gate
e2e` on the dev machine with the canvas visual baselines refreshed.
</verification>
