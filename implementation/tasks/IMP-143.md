# IMP-143 - "Note" drops a note on the board, ready to type

<objective>
Pressing the "Note" tool puts a new empty note in the middle of what
the person is looking at and starts typing on it straight away. No form
opens first.
</objective>

<context>
Second half of the audit finding "Writing a note opens a form"
(2026-11-14). Do IMP-142 first: this card uses its in-place editor
(`NoteInlineEditor`).
Today "Note" opens the dialog "Add Note" ("Create a sticky note on your
canvas.", button "Create Note"). After saving, the note is always
created at the fixed spot x 100, y 100
(`initialPosition={{ x: 100, y: 100 }}` in `CanvasDialogs.tsx`), which
can be far from what the person is looking at.
Other tools already place new things in view with
`viewportCenterWorld(position, stageSize, zoom)` (see `handleAddTable`
in `CanvasBoard.tsx`).
</context>

<files>
`src/features/canvas/components/CanvasBoard.tsx` (`onAddNote`,
`onCreateItem`, `handleAddTable` as the pattern, `createItem`),
`src/features/canvas/components/CanvasDialogs.tsx`,
`src/features/canvas/components/CreateNoteDialog.tsx`,
`src/features/canvas/components/viewport-center.ts`,
`src/features/canvas/components/NoteInlineEditor.tsx` (from IMP-142),
`src/features/canvas/components/CanvasEmptyHint.tsx` (if IMP-141 has
landed), `src/lib/rich-text/note-format.ts`
(`EMPTY_VERSIONED_NOTE_CONTENT`).
</files>

<executor_constraints>
- Create the note through the same create call the dialog uses today
  (same route, same validation, same size 200x200). No new API.
- Keep `CreateNoteDialog` as the fallback for when live editing is not
  available.
- Keep the permission checks: only people who may edit items get the
  tool.
- One press makes one note, even on a slow connection: ignore further
  presses until the first create call has answered.
</executor_constraints>

<steps>
1. Add `handleAddNote` in `CanvasBoard.tsx`, modelled on
   `handleAddTable`:
   - if live editing is not available (the same test IMP-142 uses),
     open the existing dialog (`setNoteDialogOpen(true)`) and stop;
   - otherwise work out the centre of the visible board with
     `viewportCenterWorld(position, stageSize, zoom)` and create a NOTE
     with empty content (`EMPTY_VERSIONED_NOTE_CONTENT`), width 200,
     height 200, placed so its middle is at that centre, `tags: []`,
     `zIndex: allItems.length + 1`;
   - if another item already sits at exactly that position, move the
     new note 24 right and 24 down (repeat up to 10 times) so notes do
     not hide each other;
   - when the create call answers, select the new note and open
     `NoteInlineEditor` on it as soon as its shared text is ready;
   - if the create call fails, show the toast `The note was not
     added.`
2. Use `handleAddNote` everywhere a new note starts today: the
   toolbar's `Note` button (`onAddNote`), the item list's
   `onCreateItem`, and the `Add a note` button of the empty-canvas hint
   (IMP-141) if it exists.
3. Fallback dialog position: pass the visible centre (minus half the
   note size) as `initialPosition` to `CreateNoteDialog` instead of the
   fixed `{ x: 100, y: 100 }`.
4. A note left empty stays on the board, selected, so the person can
   type later or press Delete. Do not auto-delete it.
5. If the board is zoomed out so far that IMP-142's in-place rule does
   not apply (new note under 160px wide on screen), still create the
   note in view, select it, and do not open any editor; the person can
   zoom in and double-click.
6. Tests:
   - `tests/unit/canvas-add-note-in-place.test.tsx`: pressing `Note`
     calls create with a position centred on the visible area (check
     with a panned and zoomed board), then opens the in-place editor;
     with live editing off it opens the dialog; a second press while
     the first is pending creates nothing; the 24px offset rule;
   - e2e: on a new canvas press `Note`, type "hello", press Escape,
     and find a row `note: hello` in the item list
     (`Items on <canvas name>`).
</steps>

<acceptance>
- Pressing `Note` shows a new note in the middle of the visible board
  with a blinking cursor; typing fills it; no dialog opened.
- After panning far away and pressing `Note`, the note appears where
  the person is looking, not at the top-left of the canvas.
- Pressing `Note` twice gives two notes that do not sit exactly on top
  of each other.
- With live editing unavailable, the old "Add note" dialog opens and
  its note is created in view.
- Tags for the new note can be added through `Tags` (IMP-142).
</acceptance>
