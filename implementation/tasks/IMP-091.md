# IMP-091 - Import bookmarks from a browser, Pocket or Raindrop

<objective>
Someone moving to Memoria brings their saved links with them in one go,
instead of starting from an empty Inbox.
</objective>

<context>
Approved by the owner on 2026-11-11 after the competitor review: when Pocket
closed, an importer was every rival's first move. Memoria has no importer
today. Links are saved through `saveClipBatch`
(`src/lib/services/clip-batch.ts`, at most 100 links per batch, idempotent),
duplicates are found by `src/lib/services/duplicates.ts`, the limit of
2,000 items per canvas is enforced in `src/lib/policy/capacity.ts`, and every
saved link normally gets a `link.enrich` outbox job that can spend the
owner's AI budget (`src/lib/services/link-enrichment.ts`).
</context>

<files>
`src/lib/services/clip-batch.ts`, `src/lib/services/duplicates.ts`,
`src/lib/policy/capacity.ts`, `src/lib/outbox/`, `src/app/settings/`,
`src/app/api/v1/`, `tests/api/`, `tests/integration/`.
</files>

<executor_constraints>
- The uploaded file is untrusted: size limit, Zod-validated rows, only
  `http` and `https` links, no HTML from the file is ever rendered.
- Formats: the bookmarks HTML file every browser exports (also used by
  Raindrop), and CSV files with link, title, tags and date columns (Pocket
  and Raindrop). Check a current sample of each export before fixing the
  column names.
- The import runs as a background job through the outbox and is safe to run
  twice. It never spends the AI budget unasked: AI naming and tagging of
  imported links is off unless the person turns it on for this import.
</executor_constraints>

<acceptance>
- Settings has an "Import" entry: choose a file, see a preview (how many
  links, folders and duplicates), then start.
- The person chooses where links go: the Inbox, or one new canvas per
  top-level folder. Folder names and tags from the file become tags.
- Links already saved are skipped and counted. Anything that does not fit
  the canvas or account limits is reported with a count, never dropped
  silently.
- Progress and the final result (imported, skipped, failed) are shown, and
  a second upload of the same file adds nothing.
</acceptance>

<verification>
`pnpm test:file` for the new parser and route tests; `pnpm gate fast`;
`pnpm gate integration` on the dev machine; a manual import of a real
browser export with more than 2,000 links.
</verification>
