# IMP-121 - Plain words on Status, Your data, Share and Help

<objective>
Four screens stop describing how Memoria is built and say what the person
can do, in everyday words.
</objective>

<context>
Found in the UI audit of 2026-11-14. Some on-screen sentences are written
for engineers ("versioned, checksummed JSON Lines archive", "rotating this
link permanently invalidates the old URL"). The Help page also has two
sections that repeat each other ("Embeds, timer, and AR" and "Optional
surfaces"). Rule used: write in plain language, for the reader.
This card changes words only. It changes no behaviour.
</context>

<files>
`src/app/status/page.tsx`, `src/app/settings/SettingsContent.tsx`,
`src/features/canvas/components/ShareDialog.tsx`,
`src/features/canvas/components/EmbedManager.tsx`, `src/app/help/page.tsx`.
</files>

<executor_constraints>
- Change text only. Do not change props, handlers, API calls or layout.
- Use the new text exactly as written below (same capitals, same full
  stops). Escape apostrophes the way the file already does (`&apos;`).
- If a test expects an old sentence, change the test to the new sentence.
  Never delete an assertion to get a pass.
</executor_constraints>

<steps>
Replace each "Old" text with the "New" text.

1. `src/app/status/page.tsx`, the `description` prop.
   Old: `A public summary reports availability without exposing dependency
   names, credentials, or connection details.`
   New: `Shows whether Memoria is working right now.`

2. `src/app/settings/SettingsContent.tsx`, section "Download your data".
   Old: `Build a versioned, checksummed JSON Lines archive of your profile,
   workspaces, canvases, items, sharing settings, comments, activity,
   preferences, and authorized upload objects. Large exports run in the
   background and expire after 24 hours.`
   New: `Download one file with everything you have stored: your profile,
   workspaces, canvases, items, sharing settings, comments, activity,
   preferences and uploaded files. A large download is prepared in the
   background, and the file is removed after 24 hours.`

3. `src/features/canvas/components/ShareDialog.tsx`.
   - Old: `Disabling sharing or rotating this link permanently invalidates
     the old URL.`
     New: `If you turn sharing off or make a new link, the old link stops
     working for good.`
   - Old button text `Rotate public link` -> New `Make a new link`.
   - Old busy text `Rotating…` -> New `Making a new link…`.
   - Old confirm title `Rotate public link?` -> New `Make a new link?`.
   - Old confirm button `Rotate link` -> New `Make a new link`.
   - Old success message `Public link rotated. The previous URL is
     permanently invalid.` -> New `New link made. The old link no longer
     works.`
   - Old error text `Failed to rotate public link` -> New `Could not make a
     new link`.

4. `src/features/canvas/components/EmbedManager.tsx`.
   - Field label `Embed label` -> `Name for this embed`.
   - Field label `Allowed origins` -> `Websites that may show it`.
   - Helper text `Separate multiple origins with spaces or commas.` ->
     `Type each website address in full, for example https://example.com.
     Separate several with spaces or commas.`

5. `src/app/help/page.tsx`.
   - Delete the whole `<InfoSection title="Optional surfaces">` block. Its
     content repeats "Embeds, timer, and AR".
   - In "Recovery": old `Password recovery requires a configured production
     email provider.` -> new `Resetting a password needs email to be set up
     on this installation.`
   - In "Troubleshooting": old `Check the Status page for database, cache,
     and process readiness.` -> new `Check the Status page to see whether
     Memoria is working.`
   - In "Troubleshooting": old `contact the operator of this installation
     with the request identifier shown in the response.` -> new `contact
     whoever runs this installation and give them the request ID shown in
     the error message.`
   - In "Sharing roles": turn the first sentence into a list of four short
     lines, one per role, in this order and wording:
     `Viewers can read a canvas and look at earlier versions.`
     `Commenters can also add comments.`
     `Editors can also change items, and save or restore versions.`
     `Owners can also manage sharing and delete the canvas.`
     Keep the sentence about automatic snapshots unchanged, after the list.

6. Run `grep -rn "Optional surfaces\|Rotate public link\|Allowed origins\|Embed label\|checksummed" src tests`.
   Every remaining match in `tests/` must be updated to the new text.
</steps>

<acceptance>
- None of these appear in user-visible text any more: `without exposing
  dependency names`, `checksummed`, `JSON Lines`, `permanently invalidates`,
  `Rotate public link`, `Allowed origins`, `Embed label`, `Optional
  surfaces`, `configured production email provider`, `process readiness`.
- The Help page has no "Optional surfaces" heading and still has the
  "Embeds, timer, and AR" section.
- Making a new share link still works and shows `New link made. The old
  link no longer works.`
</acceptance>
