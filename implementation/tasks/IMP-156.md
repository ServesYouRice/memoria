# IMP-156 - Measure the production image

<objective>
The production image is built once after the build-cache fix (IMP-144) and
is under 1 GB (handbook plan step 2, RUN-ME-2, CHK-ME-2).
</objective>

<files>
`Dockerfile`, `Dockerfile.capture`, `package.json`.
</files>

<executor_constraints>
Slim only where clearly safe: a package only the optional capture worker
needs does not belong in the main image.
</executor_constraints>

<acceptance>
Size and the largest layers recorded in the commit; under 1 GB.
</acceptance>
