# IMP-065 - "You saved this already"

<objective>
Saving a link that is already in the user's boards says so and offers "open the existing one" instead of quietly making a duplicate.
</objective>

<files>
`src/app/api/v1/extensions/clip/route.ts`, `src/lib/agents/mcp.ts`, `ItemEmbedding` in `prisma/schema.prisma`, new `src/lib/services/duplicates.ts`
</files>

<acceptance>
- Exact matches use a normalized URL (lowercase host, no tracking parameters such as `utm_*`, no trailing slash or fragment) and need no AI.
- When embeddings are configured, near-duplicates (same article, different URL) are flagged as "looks similar", never blocked; this fills `ItemEmbedding` from the IMP-064 job.
- Clip and batch clip responses report duplicates; the extension and share screen show them, and the agent `inbox_save` result names the existing item.
- A schema change, if needed, ships with a Prisma migration.
</acceptance>

<verification>
`pnpm test -- --run` (URL normalization cases, duplicate responses); `pnpm gate integration` if a migration or index is added.
</verification>
