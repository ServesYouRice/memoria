# IMP-065 - New items file themselves into the right board

<objective>
Items landing in the Inbox get a suggested home board ("looks like Rome trip"); the user accepts with one tap, or turns on auto-accept, and can always undo.
</objective>

<files>
`src/lib/agents/piles.ts`, `src/lib/agents/service-core.ts`, `src/features/canvas/components/`, `src/lib/ai/service.ts`
</files>

<acceptance>
- After IMP-063 tags an item, a job proposes a target board from the user's board names, tags and (when present) embeddings; it files a suggestion through the existing suggestion and ChangeSet path.
- The Inbox shows the suggested board on each item with Accept and Dismiss; a per-user "file automatically" setting accepts suggestions above a confidence threshold.
- Every move is a ChangeSet that can be reverted in one step; dismissed suggestions are not re-proposed for the same item.
- Without AI, suggestions come from matching tags and board names only.
</acceptance>

<verification>
`pnpm test -- --run` (suggestion, auto-accept threshold, revert, no re-propose); `pnpm gate e2e` for the Inbox accept flow (DEC-002 machine).
</verification>
