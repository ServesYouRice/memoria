# IMP-083 - Dashboard: previews, starter row and visible search

<objective>
The dashboard helps people start and find things: canvas cards show what is
inside, a new user gets obvious first steps, and search is in plain sight.
</objective>

<context>
The 2026-11-11 UI review found: canvas cards show a grey brush instead of a
preview (`CanvasCard.tsx` falls back when `thumbnail` is empty;
`use-canvas-thumbnail.ts` should create one after a 3s pause, but the seeded
sample canvases had none even after being opened); a new user sees an almost
empty page with a single "New canvas" button; search hides behind an icon
and Ctrl+K; the "Recent Activity" box (`ActivityFeed.tsx`) takes a third of
the page even when empty.
</context>

<files>
`src/features/dashboard/components/DashboardContent.tsx`,
`src/features/dashboard/components/CanvasCard.tsx`,
`src/features/dashboard/components/ActivityFeed.tsx`,
`src/features/canvas/hooks/use-canvas-thumbnail.ts`,
`src/components/layout/AppShell.tsx`, `tests/unit/`.
</files>

<executor_constraints>
Do not offer templates or canvas duplication unless their
`LAUNCH_CAPABILITIES` switch is on. Selection, bulk delete and sorting keep
working.
</executor_constraints>

<acceptance>
- A canvas with items shows a preview on its card once it has been opened
  and edited; the cause of the missing previews is found and tested. Cards
  without a preview show a coloured placeholder with the canvas initial.
- A starter row offers "Blank canvas", "Save a link" and "Open Inbox".
- Desktop shows a search field in the top bar that opens the existing
  search, with its shortcut hint; phones keep an icon.
- With no activity the activity box is hidden and the cards use the width.
- `dashboard-bulk-delete`, `dashboard-selection-scope` and
  `dashboard-activity-feed` unit tests pass.
</acceptance>

<verification>
`pnpm test:file` for the three dashboard tests and any new one;

empty and a filled dashboard at 1440x900 and 390x844, light and dark.
</verification>
