# IMP-056 - Deploy Memoria on the k3s cluster

<objective>
Memoria runs on the shared k3s cluster through the private `infra` repo
(`apps/memoria/`), with staging and production overlays, like the other apps.
</objective>

<context>
The infra repo has no `apps/memoria/` yet. A push to infra `main` deploys, so
this card changes production and needs the owner's go-ahead (DEC-001).
</context>

<files>
infra: `apps/memoria/`, `apps/kustomization.yaml`, `platform/databases/`;
memoria: `Dockerfile`, `docs/operations/`.
</files>

<acceptance>
- App, sync, worker and scheduler Deployments plus a migration Job per
  environment, using the shared PostgreSQL 16, Valkey and R2.
- Ingress routes `/api/collaboration/*` to the sync service with WebSocket
  support; the ingress CIDR is set in `TRUSTED_PROXY_CIDRS`.
- Secrets are SOPS-encrypted; a restore is proven before real data (infra
  `docs/recovery.md`).
</acceptance>

<verification>
`kustomize build` for both overlays; staging smoke (`pnpm smoke` against
staging); restore drill.
</verification>
