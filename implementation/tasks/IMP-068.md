# IMP-068 - Ask your boards, and tell them what to do

<objective>
One box where the user asks "what was that knife site I saved?" or says "make a Japan board from everything about Japan" and Memoria answers from their items or files the action as a suggestion.
</objective>

<files>
`src/app/api/v1/ai/chat/route.ts`, `src/app/api/v1/search/`, `src/lib/agents/piles.ts`, `src/lib/agents/service-core.ts`, new command palette UI under `src/features/`
</files>

<acceptance>
- Questions retrieve the user's own items (search, plus embeddings when present) and answer with links to the items used; nothing from other users is ever retrieved.
- Commands are limited to a small allow-list (create board, move items, make pile, archive) and always become a suggestion the user approves; the AI never writes directly.
- Works from the keyboard on desktop and as a search bar on phone.
- Prompt size, budget and per-user concurrency limits apply.
</acceptance>

<verification>
`pnpm test -- --run` (retrieval scoped to the user, command allow-list, suggestion-only writes); `pnpm gate e2e` for ask-and-approve.
</verification>
