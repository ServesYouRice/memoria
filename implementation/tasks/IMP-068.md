# IMP-068 - Owner approval runs propose-only agents' suggestions

<objective>
A suggestion that an agent with only the propose rung created can run once
the owner approves it, for every suggestion kind, while canvas scope still
applies.
</objective>

<context>
Only users can approve suggestions. Pile suggestions (`canvas-piles`) already
execute under the proposing agent's propose rung and canvas scope. The
`canvas-item-create`, `canvas-item-batch-create`, knowledge entity and
knowledge relation branches still require a direct-write rung, so suggestions
from default OAuth connections (rungs 0-3) fail at execution after approval.
External webhook execution must keep requiring rung 8.
</context>

<files>
`src/app/api/agent/v1/actions/route.ts`, `src/lib/agents/mcp.ts`,
`src/lib/agents/piles.ts` (reference behavior).
</files>

<steps>
1. In both executors, require the propose rung plus canvas scope for the
   internal-organization kinds listed above; leave external webhooks as is.
2. Cover a rung 0-3 profile proposing, the owner approving, and execution
   succeeding for each kind; cover webhook execution still being refused.
</steps>

<acceptance>
- Approved internal suggestions from propose-only agents execute.
- Out-of-scope canvases and unapproved suggestions are still refused.
</acceptance>

<verification>
`pnpm test:file tests/api/agent-route-auth.test.ts`; real-PostgreSQL
`pnpm test:integration`; `pnpm lint`; `pnpm type-check`.
</verification>
