# IMP-155 - Claude web check gate

<objective>
Claude web sessions install the toolchain and services, and pushes and pull
requests wait until `.claude/hooks/check.sh` has passed on the exact code
(handbook CHK-ME-1, owner's `templates/claude-cloud`).
</objective>

<files>
`.claude/settings.json`, `.claude/hooks/`, `CLAUDE.md`.
</files>

<acceptance>
- `session-start.sh` starts PostgreSQL 18 on private port 5441.
- `check.sh` runs every gate stage a cloud session can run and passes;
  `CLAUDE.md` names the stages it leaves out and why.
</acceptance>
