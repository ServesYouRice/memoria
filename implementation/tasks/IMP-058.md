# IMP-058 - Move the runtime to Node 26 LTS in one step

<objective>
Memoria runs on Node 26 LTS everywhere at once: the local gate, both Docker
stages, the `package.json` engine range and the runtime contract test.
</objective>

<context>
Dependabot PR #71 moved only the Docker image to `node:26.13.0-alpine`, which
broke `tests/unit/runtime-alignment.test.ts` on `main`; the image was put back on
24.20.0. `docs/operations/runtime-support.md` requires the whole line to move
together after the full gates pass on the new version.
</context>

<files>
`Dockerfile`, `package.json`, `scripts/gate.mjs`,
`tests/unit/runtime-alignment.test.ts`, `docs/operations/runtime-support.md`
</files>

<acceptance>
- All pins name the same Node 26 release; the engine range rejects other majors.
- Drop the `node` major ignore in `.github/dependabot.yml`.
</acceptance>

<verification>
`pnpm gate all` on Node 26 (unit, integration, browser, build, smoke).
</verification>
