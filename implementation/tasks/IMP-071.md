# IMP-071 - Voice and photos become tidy notes

<objective>
On phone or desktop the user records a voice note or snaps a photo (receipt, whiteboard, page) and gets a clean, titled text note next to the original.
</objective>

<files>
`src/app/api/v1/upload/`, `src/lib/uploads/`, `src/lib/ai/service.ts`, `src/lib/agents/providers.ts`, `src/lib/outbox/`
</files>

<acceptance>
- The provider adapter from IMP-060 gains optional speech-to-text and image-reading; the feature is offered only when the saved provider supports it.
- Processing runs as a safe-to-repeat outbox job; the original file is kept and linked from the note.
- Upload size and type limits and the existing upload validation apply.
</acceptance>

<verification>
`pnpm test -- --run` with mocked transcription and image reading; `pnpm gate integration` for the job.
</verification>
