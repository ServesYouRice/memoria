# IMP-094 - Keep the text of saved pages

<objective>
A saved link stays useful after the website changes or disappears: Memoria
keeps the page's readable text, and can point to a web-archive copy.
</objective>

<context>
Approved by the owner on 2026-11-11: dead links are a named complaint and
rivals keep copies. Today the `link.enrich` job
(`src/lib/services/link-enrichment.ts`) fetches the page through the
SSRF-safe `fetchLinkPage` and reads its text with `extractPageText`
(`src/lib/services/link-page.ts`, at most 100,000 characters), but the
text is only passed to the AI step and then thrown away. `ItemEnrichment`
keeps the title, tags and status only.
</context>

<files>
`prisma/schema.prisma`, `src/lib/services/link-enrichment.ts`,
`src/lib/services/link-page.ts`, `src/app/api/v1/search/`,
`prisma/fts-migration.sql`,
`src/lib/ai/ask.ts`, `src/features/canvas/components/BookmarkItem.tsx`,
`docs/operations/resource-budgets.md`,
`docs/operations/account-exports.md`, `tests/integration/`.
</files>

<executor_constraints>
- Schema change with a Prisma migration; the job stays safe to run twice.
- The stored text is untrusted web content: shown as plain text only, and
  marked as data wherever it is given to AI or agents.
- Looking a link up in a public web archive sends that address to a third
  party, so it is off by default, switched on per deployment and per
  person, and never used for addresses the SSRF check refuses.
- Set a storage budget per link and per account and write it into the
  resource budgets document.
</executor_constraints>

<acceptance>
- Saving a link stores its readable text with the date it was read; links
  saved earlier are filled in by a background job.
- A bookmark offers "Read saved copy", and says when the copy was made.
- Search and "Ask" find words that appear only in the page text.
- With the archive option on, the bookmark also shows a link to an
  existing web-archive copy when one exists.
- The saved text is part of the account export and is deleted with the
  item.
</acceptance>

</verification>
