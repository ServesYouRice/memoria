# IMP-122 - Every label uses sentence case

<objective>
Buttons, titles, field labels and tooltips all use sentence case (only the
first word and real names start with a capital), so the app reads as one
voice.
</objective>

<context>
Found in the UI audit of 2026-11-14. Most of the app already writes "New
canvas" and "Shared with me". A few screens still write Title Case ("Edit
Note", "API Keys", "Recent Activity"). Rule used (GOV.UK and the app's own
majority style): sentence case everywhere.
Real names keep their capitals: Memoria, Inbox, API, AI, URL, AR, PDF,
JSON, Google, Pocket, Raindrop and other product names.
This card changes words only.
</context>

<files>
Entry points, not the full list: `src/components/RichTextEditor.tsx`,
`src/components/GlobalSearchDialog.tsx`, `src/components/CommandPalette.tsx`,
`src/components/layout/AppShell.tsx`,
`src/features/canvas/components/` (dialogs and toolbars),
`src/features/dashboard/components/ActivityFeed.tsx`,
`src/app/auth/reset-password/page.tsx`, `src/app/setup/SetupForm.tsx`,
`src/app/share/[token]/page.tsx`.
</files>

<executor_constraints>
- Change visible text, `aria-label`, `title`, `label` and `placeholder`
  values only. Do not rename variables, components, files, routes, enum
  values or API fields.
- Do not touch `src/app/auth/forgot-password/page.tsx` or the wording of
  the share page's sign-in buttons: IMP-128 and IMP-129 own those.
- When a test looks up an element by the old text, update the test to the
  new text. Never delete an assertion to get a pass.
- Other cards rename or remove some of these texts: IMP-127 (the `API
  Keys` menu entry), IMP-134 (`CommandPalette.tsx` and
  `GlobalSearchDialog.tsx` are deleted), IMP-135 (`Time Machine`,
  `Version History`) and IMP-138 (`Recent Activity`). If a text or file in
  the table is already gone or already renamed, skip that row. Never
  change a newer wording back.
</executor_constraints>

</acceptance>
