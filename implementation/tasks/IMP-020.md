# IMP-020 — Release artifact gates

<objective>
CI tests the exact production artifact and produces truthful dependency,
schema, bundle, and runtime evidence.
</objective>

<steps>
1. Build one immutable image, boot it with pinned PostgreSQL/Redis/MinIO, run
   migrations as a separate step, wait for readiness, then run API/browser smoke.
2. Add a schema-drift gate comparing committed migrations with `schema.prisma`
   and a freshly migrated database.
3. Fix App Router route-to-chunk classification. Fail if expected route groups
   are empty; record route/shared budgets and artifacts.
4. Attach production dependency/SBOM scan output. Use reviewed, expiring
   exceptions; fail when the scanner itself fails.
5. Promote the tested digest; do not rebuild. Document forward-fix/rollback
   handling for incompatible migrations.
</steps>

<acceptance>
- A green gate proves the candidate image booted and served smoke traffic.
- Bundle and advisory checks cannot pass without measuring data.
</acceptance>

<verification>
Run the new CI scripts locally/Compose where available; `pnpm lint`;
`pnpm type-check`; `pnpm build`.
</verification>
