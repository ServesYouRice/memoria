# IMP-149 - A least-privilege runtime database role

<objective>
The app, sync server and worker connect as a role that can read and write
data but not change the schema; only the migration Job uses the owner role
(handbook ME-02, platform step 8).
</objective>

<context>
The rehearsal run saw every process connect as the database owner.
</context>

<files>
`prisma/migrations/` (grants), `docs/operations/`, infra
`apps/memoria/*/app` (two connection strings).
</files>

<acceptance>
- A migration grants the runtime role table, sequence and default
  privileges; it cannot `CREATE`, `ALTER` or `DROP`.
- The integration suite passes as the runtime role.
</acceptance>

<verification>
`pnpm gate integration` with the runtime role.
</verification>
