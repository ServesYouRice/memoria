# IMP-087 - Same page width and top bar everywhere

<objective>
Moving between pages feels steady: titles start at the same place, and the
app's top bar never disappears for someone who is signed in.
</objective>

<context>
From the 2026-11-11 UI review. `AppShell` takes `maxWidth` (default `lg`);
API keys, Notifications, Recap, Search and Settings pass `md` and Share
target passes `sm`, so the page title jumps sideways between pages. Help,
Status, Privacy and Terms use `PublicInfoPage.tsx`, which has no app top
bar, so a signed-in user has only the browser's Back button.
</context>

<files>
`src/components/layout/AppShell.tsx`,
`src/components/layout/PublicInfoPage.tsx`, the pages that pass `maxWidth`,
`tests/unit/app-shell-accessibility.test.tsx`.
</files>

<executor_constraints>
Keep the single skip link, navigation landmark and current-page marker that
the launch contract test checks. Public pages stay readable when signed
out and must not require a session.
</executor_constraints>

<acceptance>
- Signed-in pages share one outer width, so the top bar content and the
  page title line up on every page; narrow reading pages use an inner
  column instead of a narrower shell.
- Signed-in users see the normal top bar on Help, Status, Privacy and
  Terms; signed-out visitors see a simple bar with the logo and "Sign in".
- No sideways scroll at 390px wide.
</acceptance>

<verification>
`pnpm test:file tests/unit/app-shell-accessibility.test.tsx
tests/unit/launch-surface-contract.test.ts`; `pnpm gate fast`;
`pnpm gate e2e` on the dev machine; screenshots of Dashboard, Search,
Settings and Help at 1440x900, signed in.
</verification>
