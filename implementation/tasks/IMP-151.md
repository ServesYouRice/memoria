# IMP-151 - OpenTelemetry; drop `@vercel/analytics`; runtime browser Sentry address

<objective>
Traces and metrics go out over OpenTelemetry, `@vercel/analytics` is gone,
and the browser reads its Sentry address at runtime instead of a build
argument (handbook ME-03).
</objective>

<context>
`Dockerfile` bakes `NEXT_PUBLIC_SENTRY_DSN` into the image, so one image
cannot serve staging and production. The app is not hosted on Vercel.
</context>

<files>
`package.json`, `Dockerfile`, `src/instrumentation*.ts`,
`docs/operations/observability.md`.
</files>

<acceptance>
- No `@vercel/analytics` import.
- One image works with different Sentry addresses per environment.
- OTLP export switched on by setting an endpoint; off by default.
</acceptance>

<verification>
`pnpm build`; `pnpm gate container`.
</verification>
