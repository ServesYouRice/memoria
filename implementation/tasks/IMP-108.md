# IMP-108 - Tables on the canvas

<objective>
A person can put a simple table on a canvas and fill it in.
</objective>

<context>
Approved by the owner on 2026-11-11: tables are now common in whiteboards.
Memoria's item types are note, bookmark, image, drawing, shape, arrow,
text, frame, embed and poll (`ItemType` in `prisma/schema.prisma` and
`src/types/canvas.ts`); each has a validation schema in
`src/lib/validation/canvas-item.ts` and a Konva component.
</context>

<files>
`prisma/schema.prisma`, `src/types/canvas.ts`,
`src/lib/validation/canvas-item.ts`, `src/features/canvas/components/`,
`src/lib/collaboration/sync/client-session.ts`,
`src/lib/agents/item-text.ts`, `src/lib/export/export-utils.ts`,
`tests/unit/`, `tests/integration/`.
</files>

<executor_constraints>
New item type with a Prisma migration and a validated content schema with
fixed limits on rows, columns and cell length. Cells hold plain text. Every
place that lists item types (editor, read-only view, organizer, sync,
search, Ask, agents, exports) handles the new type.
</executor_constraints>

<acceptance>
- The add bar offers "Table". Cells can be edited, and rows and columns
  added, removed and resized.
- Two people can edit different cells at the same time without losing
  either change.
- The table appears in the read-only view, in the organised list, and in
  search and Ask.
- Markdown export writes a real table; PNG and PDF show it as on screen.
</acceptance>

<verification>
`pnpm test:file` for the new table tests; `pnpm gate fast`;
`pnpm gate integration` and `pnpm gate e2e` on the dev machine.
</verification>
