# IMP-025 — Job-backed maintenance and thumbnails

<objective>
Background maintenance survives restart and canvas lists avoid base64 thumbnail
payloads.
</objective>

<steps>
1. Move bookmark refresh to durable attempts/next-run/backoff. Do not bump item
   versions when visible content is unchanged.
2. Add bounded scheduled deletion for expired idempotency rows and other selected
   retention work through IMP-014.
3. Generate thumbnails from stable canvas revisions in a worker. Store a small
   private object key/revision, not base64 on the Canvas hot row.
4. Debounce/dedupe jobs, clean replaced objects, and expose queue age/failures.
5. Test restart, retries, stale revision suppression, retention bounds, object
   cleanup, and dashboard payload budget.
</steps>

<acceptance>
- Restart does not lose retry/backoff state.
- Canvas list JSON excludes base64 thumbnail bodies.
</acceptance>

<verification>
Worker/PostgreSQL/S3 integration tests; payload budget test; type/lint.
</verification>
