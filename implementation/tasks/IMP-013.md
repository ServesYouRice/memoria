# IMP-013 — Durable rich-text format

<objective>
Follow DEC-006: store one versioned safe format without silently stripping the
formatting exposed by the editor.
</objective>

<steps>
1. Define the selected content schema with version, size/depth limits, allowed
   nodes/marks/links, and plain-text extraction.
2. Validate and sanitize identically on every create/update/template/import path.
3. Migrate existing note strings safely; keep export/search/snippets readable.
4. If plain text was selected, remove formatting controls and product claims.
5. Test malicious links/markup, old data, round trips, search, and exports.
</steps>

<acceptance>
- A supported formatted note round-trips exactly.
- Unsupported content is rejected or normalized visibly, never silently lost.
</acceptance>

<verification>
Validation/migration/editor tests; `pnpm type-check`; `pnpm lint`.
</verification>
