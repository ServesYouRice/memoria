# IMP-051 - Close small security leaks

<objective>
Registration no longer reveals existing accounts, the CSP allows only needed hosts, and `/api/status` is cheap and rate limited.
</objective>

<files>
`src/app/api/auth/register/route.ts`, `src/middleware/csp.ts`, `src/app/api/status/route.ts`, `src/lib/operations/readiness.ts`
</files>

<acceptance>
- Registering an existing and a new email returns indistinguishable responses.
- `connect-src` and `img-src` list explicit origins (R2, the sync path, Sentry) instead of any https/wss host.
- `/api/status` is cached for a few seconds and rate limited.
</acceptance>

<verification>
Route and CSP tests; `pnpm test -- --run`; `pnpm gate e2e` for CSP.
</verification>
