# IMP-092 - Saving from an iPhone is easy to set up

<objective>
An iPhone or iPad user can start saving links to their Inbox in a couple of
minutes, guided from inside the app.
</objective>

<context>
Approved by the owner on 2026-11-11. An installed web app cannot appear in
the iPhone Share menu, so Memoria already documents an Apple Shortcut that
posts to `/api/v1/extensions/clip/batch` with an API key
(`docs/integrations/phone-sharing.md`). Today the guide lives only in the
repository and the person must build the Shortcut by hand, action by
action. A ready-made Shortcut can only be created and shared from an Apple
device, so its link has to come from the owner.
</context>

<files>
`docs/integrations/phone-sharing.md`, `src/app/help/page.tsx`,
`src/app/api-keys/ApiKeysContent.tsx`, `src/app/share-target/`,
`tests/unit/`.
</files>

<executor_constraints>
The API key is shown once, as today, and is never put in a link or a QR
code. The guide in `docs/` stays the single source for the steps.
</executor_constraints>

<acceptance>
- Help has a "Save from your phone" section with the Android and iPhone
  steps in plain words, reachable from the API keys page.
- The API keys page offers "Create a key for my iPhone" and shows the
  server address and the new key with copy buttons.
- When a ready-made Shortcut link is configured for the deployment, the
  section shows an "Add the Shortcut" button; without it, the hand-built
  steps are shown.
- On an iPhone or iPad the share page explains the Shortcut instead of
  failing silently.
</acceptance>

<verification>
`pnpm test:file <new test>`; `pnpm gate fast`; a real save from an iPhone
following only the in-app steps (owner, on a device).
</verification>
