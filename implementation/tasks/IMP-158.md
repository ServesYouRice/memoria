# IMP-158 - Measure the outbox worker with real PDFs on the server

<objective>
The outbox worker's memory is measured on the shared server while it reads
real PDFs (up to the 256 MB heap in `src/lib/policy/resource-budgets.ts`),
and `infra`'s worker limit is set from that figure (handbook CHK-ME-2; the
2026-11-12 run measured 146 MB before PDF reading existed).
</objective>

<files>
`src/lib/policy/resource-budgets.ts`, `docs/operations/resource-budgets.md`.
</files>

<acceptance>
Peak worker memory with a batch of large PDFs recorded; the limit in
`infra` covers it.
</acceptance>
