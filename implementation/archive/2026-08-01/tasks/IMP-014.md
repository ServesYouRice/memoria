# IMP-014 — Durable outbox and worker foundation

<objective>
Database state and external work can be committed atomically, leased safely,
retried idempotently, inspected, and replayed.
</objective>

<files>
`prisma/schema.prisma`, `prisma/migrations/`, `src/lib/db.ts`,
`scripts/scheduler.mjs`, `src/lib/logger/index.ts`, `package.json`,
plus a new `src/lib/outbox/` module.
</files>

<steps>
1. Add a migration/model for outbox jobs: type, minimized payload, dedupe key,
   status, attempts, next run, lease owner/expiry, timestamps, and last safe
   error. Define retention and indexes.
2. Add transactional enqueue helpers and a separate worker command/process.
3. Claim bounded batches with PostgreSQL-safe leasing; recover expired leases.
4. Implement exponential backoff, max attempts, dead-letter state, structured
   metrics/logs, graceful shutdown, and idempotent handler contracts.
5. Keep secrets/tokens out of plaintext payloads; store references or encrypted
   values where needed.
6. Test concurrent workers, crash after side effect, crash before completion,
   retry, dedupe, lease expiry, and dead-letter replay against PostgreSQL.
</steps>

<acceptance>
- Enqueue and domain mutation share one transaction.
- Two workers cannot own the same active lease.
</acceptance>

<verification>
Real-DB worker tests; `pnpm type-check`; `pnpm lint`; worker smoke run.
</verification>
