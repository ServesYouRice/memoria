<claim>
Infinite Loop on Process Exit via Asynchronous beforeExit Handler in Database Client (high)

In Node.js, the 'beforeExit' event is emitted when the event loop empties and no additional work is scheduled. If a registered 'beforeExit' listener executes asynchronous work, Node.js continues running and emits 'beforeExit' again when that work completes. In src/lib/db.ts, the listener is registered using process.on rather than process.once and calls shutdown('beforeExit'), which performs asynchronous work (await prisma.$disconnect()). Upon resolution, the event loop empties again, causing Node.js to trigger 'beforeExit' repeatedly in an infinite loop and preventing the process from terminating naturally.
</claim>
