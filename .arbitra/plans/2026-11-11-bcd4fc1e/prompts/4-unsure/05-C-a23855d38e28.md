prisma/seed.ts does not load environment variables via dotenv (medium)

`prisma/seed.ts` initializes `PrismaPg` directly using `process.env.DATABASE_URL` but does not import `dotenv/config`. In contrast, `prisma.config.ts` and `prisma.config.integration.ts` include `import "dotenv/config";`. If `prisma/seed.ts` is invoked directly (e.g., via `tsx prisma/seed.ts` or `npm run seed`) outside of a process that has already exported `DATABASE_URL`, `process.env.DATABASE_URL` will be undefined, causing client initialization and database connection to fail.
</claim>
