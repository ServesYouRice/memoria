<goal>
Let AI chat follow-ups see earlier turns. AIDialog (src/features/canvas/components/AIDialog.tsx) sends a bounded history of prior user/assistant messages. chatSchema (src/lib/validation/ai.ts) validates it. POST in src/app/api/v1/ai/chat/route.ts counts it in the runBudgetedAi prompt and forwards it to generateText (src/lib/ai/service.ts). Both provider adapters emit it as ordered role messages before the latest user message.

This matters because it fixes:
- Chat omits the conversation displayed to the user (medium)
  Although AIDialog accumulates and displays a conversation, each request contains only the latest message and canvas context. The server passes that single message to stateless provider requests. Previous user messages and assistant answers are never available for follow-up questions.
</goal>
