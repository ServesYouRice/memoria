<goal>
Pass the outbox abort signal through readOriginal (src/lib/uploads/upload-note.ts) into readPrivateUploadObject (src/lib/uploads/private-storage.ts). The S3 GetObject request then honours abortSignal, and the response stream is cancelled when the signal fires, so a timed-out attempt stops its storage I/O.

This matters because it fixes:
- Upload-note storage reads survive worker cancellation (medium)
  readOriginal checks cancellation only before awaiting the next chunk. Neither the pending storage request nor reader.read is connected to the abort signal, and releaseLock does not cancel the stream. The worker races the handler against cancellation, so a timed-out attempt can remain blocked in storage I/O after the worker has moved on.
</goal>
