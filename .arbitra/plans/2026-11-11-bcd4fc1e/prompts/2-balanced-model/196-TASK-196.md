<goal>
In the legacy branch of normalizeNoteContent (src/lib/rich-text/note-format.ts), parse the sanitized legacy HTML into a TiptapNode document. It keeps paragraphs, headings h1–h3, lists, blockquotes, code blocks, hard breaks, and the bold/italic/strike/code/link marks, with entities decoded. The branch then returns text = renderNode(document) and plainText = extractText(document).trim().

This matters because it fixes:
- Legacy note conversion loses formatting and corrupts escaped text (medium)
  Legacy HTML is converted into one unmarked text node rather than parsed into a rich-text document. This removes formatting, links and block boundaries. stripHtml also leaves HTML entities encoded, so text such as A &amp; B becomes literal entity text in the editor. The returned HTML and document therefore represent different content; subsequent versioned normalization uses the degraded document.
</goal>
