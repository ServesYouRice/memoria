# ADRs

This directory contains Architectural Decision Records documenting key decisions
for Memoria.

## Conventions

- Files are numbered sequentially as `ADR-XXXX`.
- Each ADR should include title, date, status, owners, context, decision,
  alternatives, consequences, and implementation references where useful.
- Status lifecycle: `Proposed` -> `Accepted` or `Rejected` -> optionally
  `Superseded`.
- Create a new ADR when an accepted decision changes architecture materially.
