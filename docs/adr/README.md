# ADRs

This directory contains Architectural Decision Records documenting key decisions for CanvasCollect.

Conventions
- Files are numbered sequentially (ADR‑XXXX) and contain: Title, Date, Status, Owners, Context, Decision, Alternatives, Consequences, Implementation/References as appropriate.
- Status lifecycle: Proposed → Accepted/Rejected → (optionally) Superseded.
- Create a new ADR when a proposal is accepted in SENATEcritique.md or SENATErefactoring.md, and link it from the dashboard.
